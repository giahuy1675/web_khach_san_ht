# River Hotel Hà Tiên

Website mới được dựng trên Next.js, React và TypeScript.

## Chạy trên máy

```bash
npm install
npm run dev
```

Mở `http://localhost:3000`.

## Kiểm tra

```bash
npm run lint
npm run typecheck
npm run build
```

## Triển khai

GitHub Actions triển khai nhánh `main` lên GitHub Pages. Đặt nguồn Pages thành **GitHub Actions** trong phần cài đặt repository.
